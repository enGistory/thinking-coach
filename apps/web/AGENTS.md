# Web 前端局部规则
- 仅实现当前任务要求的 Vue 3 PWA 页面与交互。
- 不得在任何 `VITE_*`、源码、Service Worker 或构建产物中放置模型 API Key。
- 核心作答默认语音；回答过程中不显示实时转写；第一答不可覆盖。
- 录音必须处理权限拒绝、格式检测、时长/大小限制、中断、重试和本地临时 Blob 清理。
- 通知只显示“突击审核已到达”，回答前不得暴露题型、能力、缺陷或来源结论。
- 对 API 类型使用生成或共享 Schema；禁止 `any` 逃逸，异常必须有用户可理解的状态。
- 运行：`pnpm lint && pnpm type-check && pnpm test && pnpm build`。
